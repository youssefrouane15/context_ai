0. Principe : les maquettes transcrites 1:1, la logique inchangée

Ce doc porte uniquement sur la structure HTML, le CSS et les icônes des trois écrans, relevés dans les sources des maquettes (captures du 05/10) : Agence_Modification-Demande.html, Agence_Modification-Bloquée.html, Caisse-Centrale_Traiter-Demande-En-Attente.html. Ce que disent les maquettesCe qui est fait
Icônes : <span class="material-symbols-outlined"> (Material Symbols, FILL 0 / wght 450 / opsz 24) — pas la police Material Icons de mat-icon. Noms exacts : arrow_back, lock_clock, lock, pending (agence) / hourglass_top (CC), check_circle, edit_note, warning, account_balance_wallet, currency_exchange, payments (GAB édition) / local_atm (GAB lecture), local_shipping, notes, add, delete, close, cancel Les composants rendent des <span class="material-symbols-outlined"> avec ces noms ; MatIconModule retiré de leurs imports ; la police est chargée dans index.html (§1). C'est pour ça que « ATM » s'affichait en texte : la ligature n'existe que dans Material Symbols.
Deux jeux de jetons : la maquette Modification-Demande (primary #00915A, texte #1b1c1c, bordure #e4e2e2, champs #bdcabe, cartes rounded-xl p-6 shadow-sm, footer h-16) ; les maquettes Bloquée et Caisse Centrale (QlickFLOW v3 : --qf-success-400 #007F4F, --qf-grey-*, .qf-card 16 px / 32 px / ombre 20 px, .qf-btn-m 36 px / .qf-btn-l 44 px, .qf-badge 24 px, .qf-field-disabled, footer h-20) La palette porte les deux jeux et deux mixins theme-edition / theme-recap qui posent des variables CSS sur le :host de la page. Écran agence : édition par défaut, theme-recap quand la demande est verrouillée (classe hôte via @HostBinding). Page Caisse Centrale : theme-recap. L'en-tête et la barre héritent des variables.
Structure : lien Retour (mb-5) → alerte .qf-alert-warning → carte en-tête → grid-cols-12 (8 / 4) → cartes Caisse (md:grid-cols-2 gap-8, lignes w-14 / x / flex-1), Devises (sous-bloc de saisie + table), Commentaire | GAB (lignes bordées « 200 DH x [ ] billets », ou bloc gris « Billets de 200 DH — Qté : [ ] » en lecture), Ramassage → footer flex justify-between px-8 Templates réécrits bloc par bloc dans cet ordre, chaque classe Tailwind transcrite en CSS (valeurs exactes : text-xs = 0.75rem/1rem, p-6 = 1.5rem, gap-3 = 0.75rem, w-14 = 3.5rem, min-w-[220px], border-l-4, …). Les commentaires du SCSS citent la classe d'origine.
Shell : bandeau « BMCI - Agence », menu latéral, titre de page = <aside> / <header> de la maquette, hors écranRien de tout ça dans les composants : l'écran commence au lien « Retour ». Le titre « Vue Agence » sur la page CC reste à traiter dans le shell (doc « alignement v2 » §6.1).
Footer : fixed bottom-0 right-0 w-[calc(100%-64px)] (menu 64 px en maquette, pas dans l'app)position: sticky; bottom: 0 sur toute la largeur de la zone de contenu, marges négatives égales au padding de la page → bord à bord, sans largeur calculée, donc sans débordement horizontal (vérifié : scrollWidth === clientWidth sur les quatre états).

    this.urgentChange.emit((evt.target as HTMLInputElement).checked);
  }

  /** Reporte les quantités par denominationCode, l'identifiant canonique des coupures. */
  private appliquerQuantites(coupures: FormArray, operations: OperationDetail[]): void {
    const quantites = new Map<string, number>();
    operations.forEach(o =>
      (o.currencyDetails ?? []).forEach(cd =>
        (cd.operationDenominations ?? []).forEach(od =>
          quantites.set(od.denomination.denominationCode, od.quantity)
        )
      )
    );

    coupures.controls.forEach(row => {
      const code = row.get('code')?.value as string;
      row.patchValue({ quantite: quantites.get(code) ?? 0 }, { emitEvent: false });
    });
  }

  private construirePayload(): DemandeFondsPayload {
    const urgent: boolean = this.form.get('urgent')?.value ?? false;
    const operations: OperationPayload[] = [];

    // GAB — SUPPLY ATM, ventilation MAD
    if (this.totalGab() > 0) {
      operations.push({
        operationType: 'ATM',
        operationSens: 'SUPPLY',
        isUrgent: urgent,
        cashDeskNumber: PARAMETRES_AGENCE.cashDeskNumber,
        currencyDetails: [this.detailMad(this.gabCoupures, this.totalGab())]
      });
    }

    if (this.totalCaisse() > 0) {
      operations.push({
        operationType: 'CASH_DESK',
        operationSens: 'SUPPLY',
        isUrgent: urgent,
        cashDeskNumber: PARAMETRES_AGENCE.cashDeskNumber,
        currencyDetails: [this.detailMad(this.caisseCoupures, this.totalCaisse())]
      });
    }

    this.commandeDeviseLignes.controls
      .filter(l => Number(l.get('montant')?.value ?? 0) > 0 && !!l.get('deviseCode')?.value)
      .forEach(l => operations.push({
        operationType: 'CURRENCY',
        operationSens: 'SUPPLY',
        isUrgent: urgent,
        cashDeskNumber: PARAMETRES_AGENCE.cashDeskNumber,
        currencyDetails: [{
          currency: { isoCode: l.get('deviseCode')!.value },
          totalAmountByCurrency: Number(l.get('montant')!.value),
          operationDenominations: []
        }]
      }));

    const ramassageParDevise = new Map<string, number>();
    this.ramassageLignes.controls.forEach(l => {
      const isoCode: string | null = l.get('deviseCode')?.value;
      const montant = Number(l.get('montant')?.value ?? 0);
      if (!isoCode || montant <= 0) { return; }
      ramassageParDevise.set(isoCode, (ramassageParDevise.get(isoCode) ?? 0) + montant);
    });
    if (ramassageParDevise.size > 0) {
      operations.push({
        operationType: 'CURRENCY',
        operationSens: 'COLLECTION',
        isUrgent: urgent,
        cashDeskNumber: PARAMETRES_AGENCE.cashDeskNumber,
        currencyDetails: Array.from(ramassageParDevise, ([isoCode, total]) => ({
          currency: { isoCode },
          totalAmountByCurrency: total,
          operationDenominations: []
        }))
      });
    }

    const ctx = this.contexteUtilisateur.contexte();
    return {
      branchCode: ctx?.agenceCode ?? '',
      user: ctx?.uid ?? '',
      establishment: PARAMETRES_AGENCE.establishment,
      operations,
      comment: (this.form.get('comment')?.value as string | null) ?? null
    };
  }

  private detailMad(coupures: FormArray, total: number) {
    return {
      currency: { isoCode: DEVISE_LOCALE },
      totalAmountByCurrency: total,
      operationDenominations: coupures.controls
        .filter(row => Number(row.get('quantite')?.value ?? 0) > 0)
        .map(row => ({
          denomination: { denominationCode: row.get('code')?.value as string },
          quantity: Number(row.get('quantite')?.value)
        }))
    };
  }
}

      this.snackBar.open(this.actions.erreur() ?? 'Erreur lors de la décision.', 'Fermer', { duration: 6000 });
    }
  }
