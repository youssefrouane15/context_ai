CauseCorrectifRecette

0. Cause

La garde accueilParProfil est posée sur la route vide '', qui est aussi l'écran « Nouvelle Demande » (routerLink="/" de la sidebar). Elle s'exécute donc à chaque navigation vers /, pas seulement à l'arrivée :

ProfilClic « Nouvelle Demande »Effet
Chef de caisse / DArouteAccueil → /listredirection vers la page déjà affichée → Angular annule → « rien ne se passe »
Super Admin h11111arrive sur / depuis le portailrien ne vérifie creer sur la route vide → écran de saisie affiché à un profil qui ne saisit pas

Correctif : (1) la garde ne redirige qu'à la première navigation (router.navigated === false = arrivée depuis le portail ou URL tapée) ; (2) la route vide exige aussi creer, comme toute route de saisie. Pour h11111 : il porte GDF_TOUTES_AGENCES (V17) → accueil sur /caisse-centrale, et #/ tapé à la main est refusé.

import { inject } from '@angular/core';
import { CanActivateFn, Router } from '@angular/router';
import { ContexteUtilisateurService } from '../../../adapters/apiAdapters/contexte-utilisateur.service';
import { ContexteGdf } from '../../../domain/domain-core/entities/contexte-utilisateur.model';

/**
 * Accueil par profil, appliqué UNE SEULE FOIS : à l'arrivée dans l'application (depuis le portail ou une URL tapée).
 *  - Caisse Centrale / Support (toutesAgences) → vue Caisse Centrale
 *  - Pôle opérations monétique               → historique GAB hors site
 *  - Agence (DA, Chef de caisse)             → historique des demandes
 * Une navigation interne vers « / » (clic « Nouvelle Demande ») n'est jamais redirigée.
 */
export function routeAccueil(ctx: ContexteGdf | null): string | null {
  if (!ctx) {
    return null;
  }
  if (ctx.habilitations.toutesAgences) {
    return '/caisse-centrale';
  }
  if (ctx.habilitations.creerMonetique) {
    return '/monetique/list';
  }
  if (ctx.habilitations.consulter) {
    return '/list';
  }
  return null;
}

export const accueilParProfil: CanActivateFn = async () => {
  const router = inject(Router);
  if (router.navigated) {
    return true;                                  // navigation interne : on laisse passer, exigePermission('creer') fait le reste
  }
  const ctx = await inject(ContexteUtilisateurService).charger();
  const cible = routeAccueil(ctx);
  return cible ? router.parseUrl(cible) : true;
};

describe('accueilParProfil', () => {
