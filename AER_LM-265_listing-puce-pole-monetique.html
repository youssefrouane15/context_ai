Listing agence / Caisse Centrale : puce « PÔLE MONÉTIQUE » pour les demandes du circuit monétique

fund-management-front · demandes-list · 23/10/2026

CauseCorrectifTestsRecette

0. Cause

chipsContenu(d) traduit chaque opération en puce (RAMASSAGE / GAB / CAISSE / DEVISES) et retombe sur return op.operationType pour un type inconnu : les opérations monétique (ALIMENTATION_GAB) s'affichent donc en code brut, avec une classe chip--alimentation_gab sans style.

Correctif : la règle se base sur le canal de la demande (DemandeFonds.canalDemande === 'MONETIQUE', champ déjà présent dans le modèle) et non sur le libellé d'opération ; une demande monétique affiche une seule puce PÔLE MONÉTIQUE, même forme que les autres, teinte violette dédiée (distincte du vert / ambre / bleu / ardoise déjà utilisés). Le code de puce reste MONETIQUE (classe CSS sans espace ni accent) ; seul le libellé affiché passe par libelleChip.

// demandes-list.regles.ts — ÉDITION : remplace la fonction chipsContenu (lignes 167-177) par ce bloc

/** AER_LM-265 : une demande du circuit monétique (canalDemande = MONETIQUE) affiche une seule puce « Pôle monétique ». */
export const CHIP_MONETIQUE = 'MONETIQUE';

/** Mêmes chips que les listings précédents : CAISSE / GAB / DEVISES / RAMASSAGE, sans doublon ; MONETIQUE pour le circuit GAB hors site. */
export function chipsContenu(d: DemandeFonds): string[] {
  if (d.canalDemande === CHIP_MONETIQUE) {
    return [CHIP_MONETIQUE];
  }
  const chips = (d.operations ?? []).map(op => {
    if (op.operationSens === 'COLLECTION') { return 'RAMASSAGE'; }
    if (op.operationType === 'ATM')        { return 'GAB'; }
    if (op.operationType === 'CASH_DESK')  { return 'CAISSE'; }
    if (op.operationType === 'CURRENCY')   { return 'DEVISES'; }
    return op.operationType;
  });
  return [...new Set(chips)];
}

/** Libellé affiché d'une puce de contenu (le code sert aussi de suffixe de classe CSS). */
export function libelleChip(code: string): string {
  return code === CHIP_MONETIQUE ? 'PÔLE MONÉTIQUE' : code;
}

  const demande = (canalDemande: string | null, operations: any[] = []): DemandeFonds =>
    ({ id: 'x', branchCode: '9000', establishment: 'RETAIL', requestStatus: 'SUBMITTED', canalDemande, operations } as DemandeFonds);

  it('demande monétique : une seule puce MONETIQUE, quelles que soient ses opérations', () => {
