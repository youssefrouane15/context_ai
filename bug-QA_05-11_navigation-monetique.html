Bug QA 05/11 — NG04002 « Cannot match any routes: 'monetique' » sous le portail

fund-management-front · demandes-monetique-list : navigation relative au parent au lieu de « /monetique » absolu · 05/11/2026

Causedemandes-monetique-list.component.tsMême défaut ailleursRecette

0. Cause

Le MFE est monté sous /portail dans le shell. demandes-monetique-list.component.ts navigue en absolu : navigate(['/monetique']) et navigate(['/monetique', 'consultation', id]) → le routeur du shell cherche /monetique à la racine → NG04002. En standalone (4201) ça passait, d'où le bug découvert seulement sous le portail. demandes-list fait déjà bien : navigate(chemin, { relativeTo: this.route.parent }) — on aligne.

  // Navigation relative au parent (« /portail » sous le shell, « / » en standalone) : plus de chemin absolu « /monetique ».
  nouvelleDemande(): void { this.router.navigate(['monetique'], { relativeTo: this.route.parent }); }

  // ------------------------------------------------------------------ Pagination / ligne

  allerPage(page: number): void {
    if (page >= 0 && page < this.nombrePages() && page !== this.pageCourante()) { this.page$.next(page); }
  }

  }
