Référentiel Zones de distribution — BDD et APITechnical Story · 8 pts · sert AER_LM-268 (front) et AER_LM-259 (dropdown fiche agence)

1. Contexte et décisions

AER_LM-270 crée le référentiel des zones de distribution (zones de livraison) qui alimente la liste déroulante « Zone » de la fiche agence (AER_LM-259). Le tech lead a tranché : table dédiée, distincte des unités d’organisation orga_unit de type ZONE.

Ce que ce ticket livre
  • Script Flyway V14 : séquence, table zone_distribution, seed CASA / RABAT.
  • Tranche complète clonée sur la tranche Zone existante : entité → repository → service → mapper → facade → contrôleur.
  • 7 endpoints dont GET /actives, pensé pour le dropdown de 259.
Choix à connaître
  • Nommage : « zone de distribution » (tech lead) plutôt que « zone de livraison » (Jira 268). Tout est préfixé ZoneDistribution pour ne pas collisionner avec ZoneController / ZoneDTO existants.
  • Nouveau sous-package referentiel (controller, dto, entities, service) : les référentiels ne sont ni des habilitations ni de l’organisation.
  • Unicité en base sur code (contrainte uk_zone_distribution_code) en plus du contrôle applicatif insensible à la casse — orga_unit n’en a pas, c’est une amélioration.
  • @NotBlank sur les chaînes des DTO d’écriture (les DTO agence utilisent @NotNull, qui laisse passer "").
  • Pas de table zone_distribution_aud : aucune entité n’est @Audited dans le projet, la table serait morte.
  • Sécurité : même @PreAuthorize que ZoneController (le référentiel est consommé par l’écran admin agence).
Gateway — à vérifier avant le premier appel depuis le frontLa route /api/v1/public/users/referentiels/** est nouvelle. Si api-gateway-ci route par préfixe /api/v1/public/users/**, rien à faire. Si elle route chemin par chemin (QfUrlsProperties), ajouter la route avant l’intégration front.

@Component
public class ZoneDistributionMapper {

    public ZoneDistributionEntity toEntity(CreateZoneDistributionDTO dto) {

            return null;
        }
        return ZoneDistributionEntity.builder()
                .actif(true)
                .code(dto.getCode())
                .name(dto.getNom())
                .build();
    }

    public ZoneDistributionDTO toDto(ZoneDistributionEntity zone) {
        if (zone == null) {
            return null;
        }
        return ZoneDistributionDTO.builder()
                .id(zone.getId())
                .code(zone.getCode())
                .nom(zone.getName())
                .actif(zone.isActif())
                .build();
    }

    public List<ZoneDistributionDTO> toDtoList(List<ZoneDistributionEntity> zones) {
        if (zones == null) {
            return null;
        }
        return zones.stream().map(this::toDto).toList();
    }

    public void toEntity(ZoneDistributionEntity zone, UpdateZoneDistributionDTO dto) {
        zone.setCode(dto.getCode());
        zone.setName(dto.getNom());
    }

package com.bnpp.irb.qlickflow.admin.facade.impl;

import com.bnpp.irb.qlickflow.admin.dto.referentiel.zonedistribution.CreateZoneDistributionDTO;
import com.bnpp.irb.qlickflow.admin.dto.referentiel.zonedistribution.UpdateZoneDistributionDTO;
import com.bnpp.irb.qlickflow.admin.dto.referentiel.zonedistribution.ZoneDistributionDTO;
import com.bnpp.irb.qlickflow.admin.exceptions.DuplicateException;
import com.bnpp.irb.qlickflow.admin.facade.ZoneDistributionFacade;
import com.bnpp.irb.qlickflow.admin.mapper.ZoneDistributionMapper;
import com.bnpp.irb.qlickflow.admin.service.referentiel.ZoneDistributionService;
import jakarta.persistence.EntityNotFoundException;
import lombok.RequiredArgsConstructor;
import org.springframework.data.domain.Page;
import org.springframework.data.domain.Pageable;
import org.springframework.stereotype.Component;
import org.springframework.transaction.annotation.Transactional;

import java.util.List;
import java.util.Optional;

@Component
@RequiredArgsConstructor
public class ZoneDistributionFacadeImpl implements ZoneDistributionFacade {

    private final ZoneDistributionService zoneDistributionService;
    private final ZoneDistributionMapper zoneDistributionMapper;

    @Override
    public Optional<ZoneDistributionDTO> findById(Long id) {
        return zoneDistributionService.findById(id)
                .map(zoneDistributionMapper::toDto);
    }

    @Override
    public List<ZoneDistributionDTO> findAll() {
        return zoneDistributionMapper.toDtoList(zoneDistributionService.findAll());
    }

    @Override
    public List<ZoneDistributionDTO> findAllActives() {
        return zoneDistributionMapper.toDtoList(zoneDistributionService.findAllActives());
    }

    @Override
    public Page<ZoneDistributionDTO> findAll(Pageable pageable) {
        return zoneDistributionService.findAll(pageable)
                .map(zoneDistributionMapper::toDto);
    }

    @Override
    @Transactional
    public ZoneDistributionDTO createZoneDistribution(CreateZoneDistributionDTO dto) {
        // Vérification unicité du code
        if (zoneDistributionService.existsByCodeIgnoreCase(dto.getCode())) {
            throw new DuplicateException(
                    "Une zone de distribution avec le code '" + dto.getCode() + "' existe déjà."
            );
        }
        // Vérification unicité du libellé
        if (zoneDistributionService.existsByNomIgnoreCase(dto.getNom())) {
            throw new DuplicateException(
                    "Une zone de distribution avec le libellé '" + dto.getNom() + "' existe déjà."
            );
        }

        var entity = zoneDistributionMapper.toEntity(dto);
        var saved = zoneDistributionService.save(entity);
        return zoneDistributionMapper.toDto(saved);
    }

    @Override
    @Transactional
    public void updateZoneDistribution(UpdateZoneDistributionDTO dto) {
        // Vérifier que la zone existe
        var zone = zoneDistributionService.findById(dto.getId())
                .orElseThrow(() -> new EntityNotFoundException("ZoneDistribution not found with id: " + dto.getId()));

        // Vérification unicité du code sur une autre zone
        if (zoneDistributionService.existsByCodeIgnoreCaseAndIdNot(dto.getCode(), dto.getId())) {
            throw new DuplicateException(
                    "Une zone de distribution avec le code '" + dto.getCode() + "' existe déjà."
            );
        }
        // Vérification unicité du libellé sur une autre zone
        if (zoneDistributionService.existsByNomIgnoreCaseAndIdNot(dto.getNom(), dto.getId())) {
            throw new DuplicateException(
                    "Une zone de distribution avec le libellé '" + dto.getNom() + "' existe déjà."
            );
        }

        zoneDistributionMapper.toEntity(zone, dto);
        zoneDistributionService.save(zone);
    }

    @Override
    public void toggleActivation(Long id) {
        zoneDistributionService.toggleActivation(id);
    }
}

5. Tests Postman

Collection AER_LM-270_zones-distribution.postman_collection.json livrée à côté de ce document. Variables : baseUrl (défaut http://localhost:8091) et token. Les requêtes s’enchaînent : la création stocke zoneId pour les suivantes.

  1. Listing initial → 2 zones seedées, triées par libellé.
  2. Création FES → 201, data.id mémorisé.
  3. Création doublon fes (casse différente) → 409.
  4. Consultation par id → 200, code = FES.
  5. Mise à jour libellé → 200.
  6. Mise à jour id inconnu → 404.
  7. Toggle → 200, puis /actives ne contient plus FES.
