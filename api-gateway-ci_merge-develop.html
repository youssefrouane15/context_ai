0. Spécificités gateway

  • Pas de Flyway, pas de front : les conflits seront dans 3 zones — les YAML (routes, CORS, variables), la sécurité (SecurityConfig, filtres mock/oauth/relay), le pom.xml.
  • Ce que develop-omega a ajouté (261+) : route qf-fund-management (Path=/api/v1/public/fund-management/** + RewritePath + PreserveHostHeader), variable QF_MS_FUND_MANAGEMENT_URL, origin CORS QF_MS_FUND_MANAGEMENT_FRONT_PORTAL_URL (4201), mode mock (MockAuthController, MockJwtService, QfMockTokenRelayFilter, cookie QF_MOCK_SESSION), DedupeResponseHeader CORS.
  • Règle : on garde les deux apports partout ; en cas de doute sur un fichier develop (DC / Mainlevée / autre équipe), version develop + réapplication de notre delta.
  • Pas de rebase, pas de --ours/--theirs en bloc sur les YAML.
