Modif 3 · Le SCSS

Le mécanisme du survol SCSS — AJOUTER À LA FIN

En clairLes boutons sont toujours dans la page mais à opacity: 0 (invisibles). La règle tbody tr:hover .btn-action = « souris sur la ligne → montre SES boutons ». Le transition donne le fondu de la maquette. Fidélité maquette : sur une ligne Archivé, le bouton archive reste masqué même au survol (:disabled). Et :focus-visible garde l'accessibilité clavier (navigation Tab).
fund-management-list.component.scss — à la fin du fichier
.chip-statut {
  display: inline-flex;
  align-items: center;
  gap: 6px;

  svg { flex: none; }
}

.btn-action {
  opacity: 0;
  transition: opacity 0.15s;
  background: none;
  border: none;
  cursor: pointer;
  color: #5c6b63;
  padding: 6px;
  border-radius: 6px;

  &:hover { background: #eef4f1; color: #0e7d5a; }
  &:focus-visible { opacity: 1; }
  &:disabled { opacity: 0 !important; cursor: default; }
}

tbody tr:hover .btn-action { opacity: 1; }
