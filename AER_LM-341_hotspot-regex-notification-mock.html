fund-management-external-services · nettoyer() sans regex à backtracking · 17/11/2026

Le hotspotNotificationMockAdapterVérification

0. Le hotspot

Règle Sonar S5852 (regex vulnérable au backtracking) sur replaceAll("^_+|_+$", "") : sur une chaîne faite d'une longue suite de _, le moteur de regex essaie un nombre de combinaisons qui croît en carré de la longueur → déni de service possible.
Fix : la première regex ([^A-Za-z0-9_-]+, linéaire) est conservée ; le retrait des _ de début et de fin est fait par deux boucles simples, en temps linéaire. Même résultat, plus de regex à risque. Aucune dépendance ajoutée.

    private static String nettoyer(String s) {
        String remplace = s.replaceAll("[^A-Za-z0-9_-]+", "_");
        // Retrait des « _ » de début et de fin sans regex (Sonar S5852 : "^_+|_+$" = backtracking polynomial)
        int debut = 0;
        int fin = remplace.length();
        while (debut < fin && remplace.charAt(debut) == '_') {
            debut++;
        }
        while (fin > debut && remplace.charAt(fin - 1) == '_') {
            fin--;
        }
        return remplace.substring(debut, fin);
    }
