Fix — Bouton Soumettre aligné sur le pattern btn-action

Le bouton actuel est un mat-icon-button + matTooltip : son tooltip ne s'affiche pas et il reste visible en permanence, contrairement à tes boutons Voir/Télécharger. On le remplace par un clone exact de ton bouton Télécharger (mêmes classes, tooltip natif title, apparition au survol de la ligne), avec un seul ajout SCSS : rester visible pendant la soumission.

02/09/2026 · fund-management-front (retail) · fund-management-list : html + scss + ts

1Pourquoi le bouton actuel ne se comporte pas comme les autres

ComportementTes boutons Voir / TéléchargerBouton Soumettre actuel
Tooltiptitle="..." natif du navigateur → s'affichematTooltip → ne s'affiche pas (module/config non câblés pour ce contexte)
Visibilité.btn-action { opacity: 0 } + tbody tr:hover .btn-action { opacity: 1 } → apparaît au survol de la lignemat-icon-button sans la classe btn-action → toujours visible
StyleSVG inline 18×18, stroke="currentColor", hover vertIcône Material, ripple, taille différente
Principe du fix : hériter du markup existant au lieu d'en imposer un nouveau. En clonant le bouton Télécharger (mêmes classes, même mécanisme), le tooltip et l'apparition au survol viennent gratuitement de ton SCSS actuel. Un seul cas particulier à couvrir : ton SCSS a &:disabled { opacity: 0 !important } — pendant la soumission le bouton disparaîtrait complètement. On ajoute donc une classe d'état est-en-cours qui le maintient visible avec un sablier.

3fund-management-list.component.scss — l'état « en cours » reste visible

src\app\features\fund-management\presenter\pages\fund-management-list\fund-management-list.component.scssÀ AJOUTER — à l'intérieur du bloc .btn-action existant, juste après la ligne &:disabled { ... }
  // Soumission en cours : le bouton est disabled mais doit rester visible (sablier)
  &.est-en-cours { opacity: 1 !important; cursor: wait; }
Sans cette ligne, ta règle existante &:disabled { opacity: 0 !important } ferait disparaître le bouton pendant l'appel — l'utilisateur croirait que rien ne se passe. Avec elle : clic → l'avion devient une horloge, visible, non cliquable → puis la ligne passe « Soumise » et le bouton disparaît (le *ngIf="peutSoumettre(d)" devient faux car le statut n'est plus INITIATED).

Vérification rapide avant de supprimer : Ctrl+Maj+F sur matTooltip dans le dossier fund-management-list — s'il ne reste aucune occurrence après le remplacement du bouton, l'import part. Un module importé sans usage, c'est du poids mort dans le bundle et du bruit à la relecture.
