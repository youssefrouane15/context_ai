Validation du montant sans ventilation en coupures

Commande devises & ramassage renvoient 422 « montant fourni (100) ne correspond pas au calculé (0) » — correction de la règle domaine, retail + corpo, + sens d'opération côté front

19/08/2026

0Diagnostic

SymptômeCauseCorrection
POST /cash → 422 pour une commande devises (EUR, 100) ou un ramassage.CashOperation.validateAndComputeTotal recalcule detailTotal à partir des coupures et exige totalAmountByCurrency == detailTotal. Sans ventilation (operationDenominations: []), detailTotal = 0, donc tout montant saisi est rejeté.La règle « montant = somme des coupures » ne s'applique que si une ventilation est fournie. Sans ventilation, le montant est déclaratif : obligatoire et strictement positif.
La commande devises part avec operationSens: "COLLECTION".Construction du payload dans le composant : une commande est un approvisionnement (SUPPLY), COLLECTION est réservé au ramassage. Effet : la liste la classerait « RAMASSAGE » au lieu de « DEVISES ».Forcer SUPPLY pour l'opération CURRENCY de la commande devises.

Règle domaine après correction, par OperationCurrencyDetail :

CasRègleMontant retenu
Ventilation fournie (≥ 1 coupure)Si un montant est fourni, il doit égaler la somme faceValue × quantity ; sinon erreur 422. Chaque coupure doit exister dans le référentiel, quantité ≥ 0.Somme calculée (écrase le montant fourni).
Aucune ventilation (commande devises, ramassage)Le montant doit être fourni et > 0 ; sinon erreur 422.Montant fourni.

package com.bmci.q360.domain.retail.entity;

import com.bmci.q360.domain.retail.enums.OperationType;
import com.bmci.q360.domain.retail.enums.RequestType;
import com.bmci.q360.domain.retail.exceptions.RetailValidationException;
import org.junit.jupiter.api.Test;

import java.math.BigDecimal;
import java.util.ArrayList;
import java.util.List;
import java.util.Map;

import static org.junit.jupiter.api.Assertions.assertEquals;
import static org.junit.jupiter.api.Assertions.assertThrows;

class CashOperationTest {

    private static CashOperation operationDevise(BigDecimal montant) {
        Currency eur = new Currency();
        eur.setIsoCode("EUR");
        OperationCurrencyDetail detail = new OperationCurrencyDetail();
        detail.setCurrency(eur);
        detail.setTotalAmountByCurrency(montant);
        detail.setOperationDenominations(new ArrayList<>());

        CashOperation op = new CashOperation();
        op.setOperationType(OperationType.CURRENCY);
        op.setOperationSens(RequestType.SUPPLY);
        op.setCurrencyDetails(new ArrayList<>(List.of(detail)));
        return op;
    }

    @Test
    void sansVentilationLeMontantDeclareEstRetenu() {
        CashOperation op = operationDevise(new BigDecimal("100"));

        op.validateAndComputeTotal(Map.of());

        assertEquals(0, new BigDecimal("100").compareTo(op.getTotalAmount()));
        assertEquals(0, new BigDecimal("100").compareTo(op.getCurrencyDetails().get(0).getTotalAmountByCurrency()));
    }

    @Test
    void sansVentilationLeMontantEstObligatoire() {
        CashOperation op = operationDevise(null);
        assertThrows(RetailValidationException.class, () -> op.validateAndComputeTotal(Map.of()));
    }

    @Test
    void sansVentilationLeMontantDoitEtrePositif() {
        CashOperation op = operationDevise(BigDecimal.ZERO);
        assertThrows(RetailValidationException.class, () -> op.validateAndComputeTotal(Map.of()));
    }

    @Test
    void avecVentilationLeMontantDeclareDoitEgalerLaSommeDesCoupures() {
        Denomination billet200 = new Denomination();
        billet200.setDenominationCode("BILLET_200");
        OperationDenomination ligne = new OperationDenomination();
        ligne.setDenomination(billet200);
        ligne.setQuantity(2);

        CashOperation op = operationDevise(new BigDecimal("300"));   // faux : 2 × 200 = 400
        op.setOperationType(OperationType.CASH_DESK);
        op.getCurrencyDetails().get(0).setOperationDenominations(new ArrayList<>(List.of(ligne)));

        assertThrows(RetailValidationException.class,
                () -> op.validateAndComputeTotal(Map.of("BILLET_200", new BigDecimal("200"))));
    }
}
