API — Traitement de la demande par l'agent Caisse Centrale

Endpoint REST qui complète la user task Camunda de la demande soumise : l'agent valide ou rejette, le microservice retrouve la tâche active sur le moteur partagé (par businessKey + tenant), la complète avec les variables de décision, puis met à jour le statut local. Architecture hexagonale respectée : port input, port output Camunda, adapter REST dans fund-management-external-services, réponse ApiResponse<T>.

1Vue fonctionnelle — qui fait quoi

Après la soumission (statut SUBMITTED), le processus BPMN arrive sur la user task de traitement. L'agent de la caisse centrale consulte la demande, puis valide ou rejette. Côté technique, compléter une user task ne passe pas par le pattern external task (réservé aux service tasks du worker) : ça passe par l'API REST du moteur Camunda (GET /task puis POST /task/{id}/complete).

Agent Caisse Centrale │ PATCH /cash/{id}/complete-task { "decision": "APPROVE", "commentaire": "..." } ▼ CashDemandController ──► CompleterTacheUseCase (port input) │ 1. charge la demande, vérifie statut == SUBMITTED (sinon 409) │ 2. CamundaTaskPort.rechercherTacheActive(businessKey=id, tenant) │ └─ aucune tâche → 422 (process pas encore sur la user task) │ 3. CamundaTaskPort.completerTache(taskId, variables décision) │ 4. statut local → VALIDATED ou REJECTED, save ▼ ApiResponse<CashRequestDTO> (200) Variables poussées à Camunda à la complétion (contrat) : demandeValidee Boolean true si APPROVE, false si REJECT → pilote la gateway du BPMN decisionAgent String "APPROVE" | "REJECT" commentaireAgent String commentaire libre (peut être vide)
Pourquoi vérifier le statut local d'abord : c'est le même principe que le CHECK constraint — la base est la source de vérité du cycle de vie. Si la demande n'est pas SUBMITTED, inutile d'appeler Camunda : 409 immédiat, message clair. Et si Camunda n'a pas encore de tâche active (le worker est peut-être en train d'exécuter les service tasks amont), on renvoie 422 sans toucher au statut : l'agent réessaie dans quelques secondes.

    import com.bmci.q360.domain.entity.enums.TaskDecision;
    import com.bmci.workflow.fund.management.service.domain.dto.TraitementTacheDTO;
    import com.bmci.workflow.fund.management.service.domain.exceptions.StatutInvalideException;
    import com.bmci.workflow.fund.management.service.domain.exceptions.TacheIntrouvableException;
    import com.bmci.workflow.fund.management.service.domain.ports.output.workflow.CamundaTaskPort;
    import java.util.HashMap;

    // --- champ à ajouter à côté des autres dépendances final (injecté par @RequiredArgsConstructor) ---
    private final CamundaTaskPort camundaTaskPort;

    // --- méthode à ajouter dans la classe ---
    @Override
    @Transactional
    public CashRequestDTO completerTache(UUID id, TraitementTacheDTO traitement) {
        if (traitement == null || traitement.getDecision() == null) {
            throw new IllegalArgumentException("La décision (APPROVE ou REJECT) est obligatoire");
        }

        // 1. Charger et verrouiller le cycle de vie
        CashRequest demande = cashDemandRepository.getCashRequestById(id);
        if (demande == null) {
            throw new DemandeIntrouvableException("Demande introuvable : " + id);
        }
        if (!"SUBMITTED".equals(demande.getRequestStatus())) {
            throw new StatutInvalideException(
                "La demande " + id + " est au statut " + demande.getRequestStatus()
                + " : seul le statut SUBMITTED peut être traité");
        }

        // 2. Retrouver la user task active sur le moteur partagé
        String taskId = camundaTaskPort.rechercherTacheActive(id.toString())
            .orElseThrow(() -> new TacheIntrouvableException(
                "Aucune tâche de traitement active pour la demande " + id
                + " : le processus n'a peut-être pas encore atteint l'étape de traitement"));

        // 3. Compléter la tâche avec le contrat de variables
        boolean validee = traitement.getDecision() == TaskDecision.APPROVE;
        Map<String, Object> variables = new HashMap<>();
        variables.put("demandeValidee", validee);
        variables.put("decisionAgent", traitement.getDecision().name());
        variables.put("commentaireAgent",
            traitement.getCommentaire() != null ? traitement.getCommentaire() : "");
        camundaTaskPort.completerTache(taskId, variables);

        // 4. Statut local — après le succès Camunda uniquement
        demande.setRequestStatus(validee ? "VALIDATED" : "REJECTED");
        return mapperTamp.toResponseDTO(cashDemandRepository.save(demande));
    }
Ordre volontaire : Camunda d'abord, statut ensuite. Si la complétion Camunda échoue, on ne touche pas au statut local → la demande reste SUBMITTED et l'agent peut réessayer. L'inverse (statut d'abord) créerait une demande VALIDATED côté base avec un processus toujours bloqué sur la tâche — incohérence qu'il faudrait compenser. Même philosophie que la saga : l'action distante réussit avant qu'on entérine localement.

Adaptation : si chez toi le statut de la demande est typé RequestStatus (enum) et non String, remplace les comparaisons/affectations par RequestStatus.SUBMITTED, RequestStatus.VALIDATED, RequestStatus.REJECTED — on a déjà corrigé des bugs String/enum dans ChangerStatutDemandeStep, on garde le typage fort partout où il existe. Idem : si ton exception 404 s'appelle autrement que DemandeIntrouvableException, réutilise la tienne (celle du submit).

package com.bmci.workflow.fund.management.external.workflow.adapter;

import com.bmci.workflow.fund.management.external.workflow.config.CamundaRestProperties;
import com.bmci.workflow.fund.management.service.domain.exceptions.CamundaCommunicationException;
import com.bmci.workflow.fund.management.service.domain.ports.output.workflow.CamundaTaskPort;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.http.MediaType;
import org.springframework.stereotype.Component;
import org.springframework.web.client.RestClient;
import org.springframework.web.client.RestClientException;
import org.springframework.web.util.UriBuilder;

import java.util.HashMap;
import java.util.List;
import java.util.Map;
import java.util.Optional;

/**
 * Adapter REST vers l'API du moteur Camunda 7 partagé.
 * - GET  /task?processInstanceBusinessKey=...&active=true&tenantIdIn=...
 * - POST /task/{taskId}/complete  { variables: { nom: { value, type } } }
 */
@Component
@Slf4j
@RequiredArgsConstructor
public class CamundaTaskRestAdapter implements CamundaTaskPort {

    private final RestClient camundaRestClient;
    private final CamundaRestProperties properties;

    @Override
    public Optional<String> rechercherTacheActive(String businessKey) {
        try {
            List<Map<String, Object>> taches = camundaRestClient.get()
                    .uri(uriBuilder -> construireUriRecherche(uriBuilder, businessKey))
                    .retrieve()
                    .body(List.class);

            if (taches == null || taches.isEmpty()) {
                log.info("Aucune user task active pour businessKey={}", businessKey);
                return Optional.empty();
            }
            if (taches.size() > 1) {
                log.warn("{} tâches actives pour businessKey={} — la première est retenue. "
                        + "Renseigner camunda.rest.task-definition-key pour lever l'ambiguïté.",
                        taches.size(), businessKey);
            }
            String taskId = String.valueOf(taches.get(0).get("id"));
            log.info("User task {} trouvée pour businessKey={}", taskId, businessKey);
            return Optional.of(taskId);

        } catch (RestClientException e) {
            throw new CamundaCommunicationException(
                "Échec de la recherche de tâche Camunda pour la demande " + businessKey, e);
        }
    }

    @Override
    public void completerTache(String taskId, Map<String, Object> variables) {
        try {
            camundaRestClient.post()
                    .uri("/task/{taskId}/complete", taskId)
                    .contentType(MediaType.APPLICATION_JSON)
                    .body(Map.of("variables", versVariablesCamunda(variables)))
                    .retrieve()
                    .toBodilessEntity();
            log.info("Tâche Camunda {} complétée avec {} variable(s)", taskId, variables.size());

        } catch (RestClientException e) {
            throw new CamundaCommunicationException(
                "Échec de la complétion de la tâche Camunda " + taskId, e);
        }
    }

    // ------------------------------------------------------------------
    // Helpers privés
    // ------------------------------------------------------------------

    private java.net.URI construireUriRecherche(UriBuilder uriBuilder, String businessKey) {
        uriBuilder.path("/task")
                .queryParam("processInstanceBusinessKey", businessKey)
                .queryParam("active", "true");
        if (properties.getTenantId() != null && !properties.getTenantId().isBlank()) {
            uriBuilder.queryParam("tenantIdIn", properties.getTenantId());
        }
        if (properties.getTaskDefinitionKey() != null && !properties.getTaskDefinitionKey().isBlank()) {
            uriBuilder.queryParam("taskDefinitionKey", properties.getTaskDefinitionKey());
        }
        return uriBuilder.build();
    }

    /** Traduit une Map Java simple vers le format typé Camunda { value, type }. */
    private Map<String, Object> versVariablesCamunda(Map<String, Object> variables) {
        Map<String, Object> resultat = new HashMap<>();
        variables.forEach((nom, valeur) -> {
            Map<String, Object> enveloppe = new HashMap<>();
            enveloppe.put("value", valeur);
            enveloppe.put("type", typeCamunda(valeur));
            resultat.put(nom, enveloppe);
        });
        return resultat;
    }

    private String typeCamunda(Object valeur) {
        if (valeur instanceof Boolean) return "Boolean";
        if (valeur instanceof Integer) return "Integer";
        if (valeur instanceof Long)    return "Long";
        return "String";
    }
}

package com.bmci.workflow.fund.management.service.domain.ports;

import com.bmci.q360.domain.entity.CashRequest;
import com.bmci.q360.domain.entity.enums.TaskDecision;
import com.bmci.q360.domain.valueobjects.CashRequestId;
import com.bmci.workflow.fund.management.service.domain.dto.CashRequestDTO;
import com.bmci.workflow.fund.management.service.domain.dto.TraitementTacheDTO;
import com.bmci.workflow.fund.management.service.domain.exceptions.StatutInvalideException;
import com.bmci.workflow.fund.management.service.domain.exceptions.TacheIntrouvableException;
import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.extension.ExtendWith;
import org.mockito.ArgumentCaptor;
import org.mockito.InjectMocks;
import org.mockito.Mock;
import org.mockito.junit.jupiter.MockitoExtension;

import java.util.Map;
import java.util.Optional;
import java.util.UUID;

import static org.junit.jupiter.api.Assertions.*;
import static org.mockito.Mockito.*;

@ExtendWith(MockitoExtension.class)
class CompleterTacheUseCaseTest {

    // Reprendre ici les MÊMES mocks que tes tests existants de CashDemandUseCaseImpl
    // (repository, mappers, denominationRepository...) + le nouveau port :
    @Mock private com.bmci.workflow.fund.management.service.domain.ports.output.repository.CashDemandRepository cashDemandRepository;
    @Mock private com.bmci.workflow.fund.management.service.domain.ports.output.repository.DenominationRepository denominationRepository;
    @Mock private com.bmci.workflow.fund.management.service.domain.mapper.CashRequestManualMapper cashRequestDomainMapper;
    @Mock private com.bmci.workflow.fund.management.service.domain.mapperTemp1.CashRequestWebMapper mapperTamp;
    @Mock private com.bmci.workflow.fund.management.service.domain.ports.output.workflow.CamundaTaskPort camundaTaskPort;

    @InjectMocks private CashDemandUseCaseImpl useCase;

    private CashRequest demandeSoumise(UUID id) {
        CashRequest demande = new CashRequest();
        demande.setId(new CashRequestId(id));
        demande.setRequestStatus("SUBMITTED");
        return demande;
    }

    @Test
    void approveDoitCompleterLaTacheEtPasserValidated() {
        UUID id = UUID.randomUUID();
        CashRequest demande = demandeSoumise(id);
        when(cashDemandRepository.getCashRequestById(id)).thenReturn(demande);
        when(camundaTaskPort.rechercherTacheActive(id.toString())).thenReturn(Optional.of("task-1"));
        when(cashDemandRepository.save(demande)).thenReturn(demande);
        when(mapperTamp.toResponseDTO(demande)).thenReturn(new CashRequestDTO());

        useCase.completerTache(id, TraitementTacheDTO.builder()
                .decision(TaskDecision.APPROVE).commentaire("ok").build());

        assertEquals("VALIDATED", demande.getRequestStatus());
        ArgumentCaptor<Map<String, Object>> variables = ArgumentCaptor.forClass(Map.class);
        verify(camundaTaskPort).completerTache(eq("task-1"), variables.capture());
        assertEquals(Boolean.TRUE, variables.getValue().get("demandeValidee"));
        assertEquals("APPROVE", variables.getValue().get("decisionAgent"));
        assertEquals("ok", variables.getValue().get("commentaireAgent"));
    }

    @Test
    void rejectDoitPasserRejected() {
        UUID id = UUID.randomUUID();
        CashRequest demande = demandeSoumise(id);
        when(cashDemandRepository.getCashRequestById(id)).thenReturn(demande);
        when(camundaTaskPort.rechercherTacheActive(id.toString())).thenReturn(Optional.of("task-2"));
        when(cashDemandRepository.save(demande)).thenReturn(demande);
        when(mapperTamp.toResponseDTO(demande)).thenReturn(new CashRequestDTO());

        useCase.completerTache(id, TraitementTacheDTO.builder()
                .decision(TaskDecision.REJECT).build());

        assertEquals("REJECTED", demande.getRequestStatus());
    }

    @Test
    void statutNonSoumisDoitLever409SansAppelerCamunda() {
        UUID id = UUID.randomUUID();
        CashRequest demande = demandeSoumise(id);
        demande.setRequestStatus("INITIATED");
        when(cashDemandRepository.getCashRequestById(id)).thenReturn(demande);

        assertThrows(StatutInvalideException.class, () ->
            useCase.completerTache(id, TraitementTacheDTO.builder().decision(TaskDecision.APPROVE).build()));

        verifyNoInteractions(camundaTaskPort);
        verify(cashDemandRepository, never()).save(any());
    }

    @Test
    void aucuneTacheActiveDoitLever422SansChangerLeStatut() {
        UUID id = UUID.randomUUID();
        CashRequest demande = demandeSoumise(id);
        when(cashDemandRepository.getCashRequestById(id)).thenReturn(demande);
        when(camundaTaskPort.rechercherTacheActive(id.toString())).thenReturn(Optional.empty());

        assertThrows(TacheIntrouvableException.class, () ->
            useCase.completerTache(id, TraitementTacheDTO.builder().decision(TaskDecision.APPROVE).build()));

        assertEquals("SUBMITTED", demande.getRequestStatus());
        verify(cashDemandRepository, never()).save(any());
    }

    @Test
    void decisionNulleDoitLeverIllegalArgumentSansRienAppeler() {
        UUID id = UUID.randomUUID();

        assertThrows(IllegalArgumentException.class, () ->
            useCase.completerTache(id, TraitementTacheDTO.builder().build()));

        verifyNoInteractions(cashDemandRepository, camundaTaskPort);
    }
}
Mockito strict respecté : chaque test déclare exactement les stubs qu'il consomme, zéro stub dans un @BeforeEach. Le test 409 et le test 422 vérifient aussi les non-appels (verifyNoInteractions, never()) — c'est ça qui prouve l'ordre « Camunda d'abord, statut ensuite ».
