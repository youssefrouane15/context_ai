Version révisée après lecture complète du codebase (35 photos). Intègre : le lazy loading d'app.routes, le composant partagé app-input, app-feedback-state, les signals, et les conventions exactes du projet. Chaque étape a son encadré « En clair » pour comprendre ce que tu fais.

Avant de coller — la carte mentale

Ce qu'on construit, en une phrase par étape

#ÉtapeEn clair
1Modèle (operation.model.ts)On décrit la forme des données que le backend renvoie — le « contrat »
2Port (fundManagement.service.ts)On déclare CE QU'ON VEUT faire (récupérer, annuler) sans dire COMMENT
3Adapter HTTPLe COMMENT : les vrais appels réseau vers ton microservice 8300
4Store → Query → Actions → FaçadeLa mémoire de la feature + son guichet unique — le composant ne parlera qu'à la façade

6La routeOn branche la page sur une URL : /list
La règle d'or du projetLe composant ne connaît QUE la façade. La façade délègue aux actions. Les actions appellent l'adapter et écrivent dans le store. Le composant lit le store (via la query) et se met à jour tout seul grâce aux signals. Sens unique, zéro triche.
Étape 1 · Le contrat de données

operation.model.ts AJOUTER À LA FIN DU FICHIER

En clairUne interface TypeScript, c'est un moule : elle dit « une DemandeFonds a un id, un statut, des opérations... ». Ça ne produit aucun code exécuté — ça permet juste à l'éditeur de te crier dessus si tu te trompes de champ. Les noms copient exactement le JSON de ton API agence (CashRequestDTO).

export interface OperationDemande {
  id: string;
  operationType: string;     // 'ATM' | 'CASH_DESK' | 'CURRENCY'
  operationSens: string;     // 'SUPPLY' | 'COLLECTION'
  operationStatus: string;   // 'INITIATED' | 'VALIDATED' | 'CANCELLED'
  isUrgent: string;          // 'YES' | 'NO'
  establishment?: string;
  createdAt?: string;
}

export interface DemandeFonds {
  id: string;
  branchCode: string;
  establishment: string;
  requestStatus: string;     // 'INITIATED' | 'VALIDATED' | 'CANCELLED'
  user?: string;
  operations: OperationDemande[];
}

Étape 3 · L'adapter HTTP

fundManagement-http.service.ts AJOUTER DANS LA CLASSE FundHttpService

En clairLe seul fichier qui connaît les URLs. Le catchError(() => of(mock)) = « si le backend ne répond pas, renvoie des fausses données » — c'est le filet du projet pour développer backend éteint. On ne met PAS de filet sur l'annulation : une annulation qui fait semblant de réussir serait un mensonge à l'utilisateur.

N'oublie pas d'ajouter DemandeFonds dans l'import operation.model en haut du fichier.

    return firstValueFrom(
      this.http.patch<DemandeFonds>(`${this.apiUrl}/${id}/cancel`, {})

En clairUn signal est une boîte qui prévient tout le monde quand son contenu change. Le store = les boîtes. La query = la vitrine pour les lire. Les actions = les seules autorisées à écrire dedans. fundMangement.actions.ts — AJOUTER dans FundManagementActions
  async loadDemandes() {
    this.store.loadingDemandes.set(true);
    this.store.errorDemandes.set(null);

    try {
      const demandes = await this.serviceHttp.getDemandes();
      this.store.demandes.set(demandes);
    } catch (e) {
      this.store.errorDemandes.set("Loading error!");
    } finally {
      this.store.loadingDemandes.set(false);
    }
  }

  async annulerDemande(id: string) {
    const demandeMaj = await this.serviceHttp.annulerDemande(id);
    this.store.demandes.update(liste =>
      liste.map(d => d.id === demandeMaj.id ? demandeMaj : d)
    );
  }

Étape 5 · La page

fund-management-list CRÉER LE DOSSIER + 4 FICHIERS

Nouveau dossier : presenter\pages\fund-management-list\, à côté du dossier de la page de ton collègue.

En clairLe composant réutilise app-input (le champ de recherche maison du projet, avec sa croix d'effacement) et app-feedback-state (les écrans « chargement / erreur / vide »). La recherche est un FormControl converti en signal via toSignal : quand tu tapes, le signal change, le computed refiltre, le tableau se redessine — sans une ligne de plomberie.
fund-management-list.component.ts
import { ChangeDetectionStrategy, Component, OnInit, computed } from '@angular/core';
import { CommonModule } from '@angular/common';
import { FormControl, ReactiveFormsModule } from '@angular/forms';
import { toSignal } from '@angular/core/rxjs-interop';
import { MatFormFieldModule } from '@angular/material/form-field';
import { MatSelectModule } from '@angular/material/select';
import { MatButtonModule } from '@angular/material/button';
import { MatIconModule } from '@angular/material/icon';
import { MatCardModule } from '@angular/material/card';
import { MatSnackBar, MatSnackBarModule } from '@angular/material/snack-bar';
import { FunManagementFacade } from '../../../adapters/localState/fundMangement.facade';
import { DemandeFonds } from '../../../domain/domain-core/entities/operation.model';
import { FeedbackStateComponent } from '../../../../../shared/presenter/components/feedback-state/feedback-state.component';
import { InputComponent } from '../../../../../shared/presenter/components/input/input.component';

@Component({
  selector: 'app-fund-management-list',
  standalone: true,
  imports: [CommonModule, ReactiveFormsModule, MatFormFieldModule, MatSelectModule,
    MatButtonModule, MatIconModule, MatCardModule, MatSnackBarModule,
    FeedbackStateComponent, InputComponent],
  templateUrl: './fund-management-list.component.html',
  styleUrl: './fund-management-list.component.scss',
  changeDetection: ChangeDetectionStrategy.OnPush
})
export class FundManagementListComponent implements OnInit {

  rechercheControl = new FormControl('', { nonNullable: true });
  statutControl = new FormControl('TOUS', { nonNullable: true });

  readonly statuts = ['TOUS', 'INITIATED', 'VALIDATED', 'CANCELLED'];

  private recherche = toSignal(this.rechercheControl.valueChanges, { initialValue: '' });
  private statut = toSignal(this.statutControl.valueChanges, { initialValue: 'TOUS' });

  demandesFiltrees = computed(() => {
    const terme = this.recherche().trim().toLowerCase();
    const statut = this.statut();
    return this.facade.demandes().filter(d => {
      const matchStatut = statut === 'TOUS' || d.requestStatus === statut;
      const matchTerme = !terme
        || d.branchCode?.toLowerCase().includes(terme)
        || d.id?.toLowerCase().includes(terme)
        || d.user?.toLowerCase().includes(terme);
      return matchStatut && matchTerme;
    });
  });

  constructor(
    public facade: FunManagementFacade,
    private snackBar: MatSnackBar
  ) { }

  ngOnInit(): void {
    this.facade.loadDemandes();
  }

  rafraichir(): void {
    this.facade.loadDemandes();
  }

  refCourte(d: DemandeFonds): string {
    return d.id ? d.id.slice(0, 8).toUpperCase() : '—';
  }

  estUrgente(d: DemandeFonds): boolean {
    return d.operations?.some(op => op.isUrgent === 'YES') ?? false;
  }

  typesOperations(d: DemandeFonds): string {
    const libelles: Record<string, string> = {
      ATM: 'GAB', CASH_DESK: 'Caisse', CURRENCY: 'Devise'
    };
    const types = (d.operations ?? []).map(op => libelles[op.operationType] ?? op.operationType);
    return [...new Set(types)].join(', ') || '—';
  }

  async annuler(d: DemandeFonds): Promise<void> {
    if (d.requestStatus === 'CANCELLED') { return; }
    const ok = confirm(`Annuler la demande ${this.refCourte(d)} et toutes ses opérations ?`);
    if (!ok) { return; }

    try {
      await this.facade.annulerDemande(d.id);
      this.snackBar.open('Demande annulée.', 'Fermer', { duration: 4000 });
    } catch (e) {
      this.snackBar.open("Erreur lors de l'annulation de la demande.", 'Fermer', { duration: 4000 });
    }
  }
}
