Fix — taille de police des listes déroulantes (select natif)

fund-management-front · 09/10/2026 · 1 fichier

CauseFichierVérification

0. Cause

Le <select> a bien font-size: 0.875rem (classe .champ), mais la liste déroulante d'un select natif est dessinée par le navigateur : sous Windows, Chrome et Edge rendent les <option> à la taille système (16 px) tant qu'on ne pose pas la taille sur les options elles-mêmes. Une règle option { … } dans le bloc .champ--select suffit ; elle s'applique à tous les selects de l'application qui utilisent cette classe (commande devises, ramassage, filtres Caisse Centrale).

Limite : aucun navigateur ne laisse styler la hauteur, l'ombre ou les bordures de ce popup natif — pour aller plus loin il faudrait un mat-select, pas justifié pour une démo. Pour encore plus petit : 0.8125rem (13 px) → 0.75rem (12 px).
