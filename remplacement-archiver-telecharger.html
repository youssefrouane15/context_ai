Remplacement du bouton « Archiver » par « Télécharger »

Composant fund-management-list — portail QlickFlow (Angular 17)

CONFORMITÉ MAQUETTES

1Analyse fonctionnelle

Les maquettes prévoient une action Télécharger sur chaque ligne du tableau des demandes, à la place de l'action Archiver actuellement implémentée (méthode annuler(d) avec confirmation et appel à facade.annulerDemande).

Le remplacement couvre trois points :

  • Template HTML : remplacer le bouton (icône, title, click handler). L'icône devient une flèche de téléchargement standard. Le bouton n'est plus désactivé pour les demandes annulées — une demande CANCELLED reste téléchargeable (justificatif / traçabilité).
  • Composant TS : remplacer annuler() par telecharger() qui récupère un fichier (Blob) via la façade et déclenche le téléchargement navigateur.
  • Façade / service : ajouter telechargerDemande(id) qui appelle le endpoint d'export du microservice avec responseType: 'blob'.
Point à valider avec Yassin : le endpoint d'export n'existe pas encore côté microservice-fund-management (le contrôleur CashDemandController n'expose que le CRUD + cancel). Il faut confirmer le format attendu (PDF ? CSV ?) et si l'export est porté par ce microservice ou par un service transverse d'édition. Le code ci-dessous suppose un endpoint GET /cash/{id}/export retournant un PDF.

2Template — fund-management-list.component.html

Remplacer le bloc du bouton « Archiver » (bouton avec title="Archiver") par :

<button class="btn-action" type="button" title="Télécharger"
        (click)="telecharger(d)">
  <svg width="18" height="18" viewBox="0 0 24 24" fill="none" stroke="currentColor"
       stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
    <path d="M21 15v4a2 2 0 0 1-2 2H5a2 2 0 0 1-2-2v-4"/>
    <polyline points="7 10 12 15 17 10"/>
    <line x1="12" y1="15" x2="12" y2="3"/>
  </svg>
</button>

L'attribut [disabled]="d.requestStatus === 'CANCELLED'" est volontairement supprimé : le téléchargement reste disponible quel que soit le statut.

3Composant — fund-management-list.component.ts

Remplacer la méthode annuler() par :

async telecharger(d: DemandeFonds): Promise<void> {
  try {
    const blob = await firstValueFrom(this.facade.telechargerDemande(d.id));

    // Déclenchement du téléchargement navigateur
    const url = window.URL.createObjectURL(blob);
    const lien = document.createElement('a');
    lien.href = url;
    lien.download = `demande-fonds-${d.id}.pdf`;
    lien.click();
    window.URL.revokeObjectURL(url);

    this.snackBar.open('Demande téléchargée.', 'Fermer', { duration: 3000 });
  } catch (e) {
    this.snackBar.open("Erreur lors du téléchargement de la demande.", 'Fermer', { duration: 4000 });
  }
}

Import à ajouter en tête de fichier si absent :

import { firstValueFrom } from 'rxjs';

4Façade et service HTTP

Dans la façade (même fichier que annulerDemande) :

telechargerDemande(id: string): Observable<Blob> {
  return this.fundManagementService.telechargerDemande(id);
}

Dans le service HTTP :

telechargerDemande(id: string): Observable<Blob> {
  return this.http.get(`${this.apiUrl}/cash/${id}/export`, {
    responseType: 'blob'
  });
}
Rappel proxy : avec la configuration locale (apiUrl: '' + proxy.conf.json), l'URL relative /api/... sera correctement routée vers la gateway — pas de traitement CORS spécifique pour le blob.

5Nettoyage et vérifications

  • Supprimer la méthode annuler() si elle n'a plus aucun usage (vérifier avec « Find Usages » dans l'IDE — l'annotation « 1 usage » visible sur ta capture correspondait au bouton supprimé).
  • Supprimer annulerDemande de la façade/service uniquement si l'annulation n'est déclenchée nulle part ailleurs (écran de détail par exemple) — sinon la conserver.
  • Vérifier que la colonne col-actions conserve son alignement (deux boutons : Voir le détail + Télécharger).
  • Tester le rendu du fichier téléchargé une fois le endpoint backend confirmé.
