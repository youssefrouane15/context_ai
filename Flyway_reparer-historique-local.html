-- Réaligne les 5 lignes sur les noms de fichiers du tech lead.
-- Règle Flyway : description = le nom du fichier après V<n>__, sans .sql, les _ remplacés par des espaces. Les 5 objets existent déjà en base : rien n'est rejoué.

COMMIT;

-- Contrôle : les 5 descriptions / scripts doivent être identiques, au caractère près, aux noms de tes fichiers renommés.
