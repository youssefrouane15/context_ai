Bug QA 09/11 — « GAB hors site » visible et inopérant pour les profils agence

fund-management (back) · CashDemandUseCaseImpl.search : canal perdu pour les profils agence → page vide · fund-management-front · option du filtre conditionnée par consulterMonetique · 09/11/2026

0. Cause

Ta capture : GET /cash?page=0&size=20&canal=MONETIQUE → 200 avec toutes les demandes de l'agence. Le filtre n'est pas ignoré par la spec : il est perdu avant. Dans CashDemandUseCaseImpl.search, pour un profil non « toutes agences », les critères sont reconstruits pour forcer branchCode — avec l'ancien constructeur à 12 arguments, sans canal (le champ a été ajouté en 13ᵉ position pour la CC/322). Résultat : canal = null → liste complète. Pour la CC (toutesAgences) les critères passent tels quels, d'où « ça marche chez eux ».

Fix, les deux couches : (1) back, règle métier dans le use case : le Monétique est le périmètre des profils toutes agences (même règle que l'export et la décision CC) → pour un profil agence, canal=MONETIQUE renvoie une page vide sans requête, et le canal est désormais transmis ; (2) front, l'option « GAB hors site » n'est proposée que si habilitations().consulterMonetique (même droit que la garde de l'écran Monétique, GDF_CONSULTER_DEMANDE_MONETIQUE, donné à CC/Support par V27). Le back reste la vraie barrière (URL forgée, autre client).

    static final String CANAL_MONETIQUE = "MONETIQUE";

    @Override
    public PageResult<CashRequestDTO> search(DemandeSearchCriteria criteria, ContexteAppelant contexte) {
        if (contexte.toutesAgences()) {
            return cashDemandRepository.search(criteria.enMasquantLesBrouillons()).map(this::enrichir);
        }
        // Profil agence : les demandes Monétique sont hors périmètre → page vide, et surtout pas « toutes les demandes
        // de l'agence » (bug QA 09/11 : le canal était perdu en reconstruisant les critères → le filtre semblait ignoré).
        if (CANAL_MONETIQUE.equals(criteria.canal())) {
            return PageResult.empty(criteria.page(), criteria.size());
        }
        DemandeSearchCriteria effectifs = new DemandeSearchCriteria(criteria.statut(), contexte.branchCode(),
                criteria.operationType(), criteria.operationSens(), criteria.recherche(), criteria.dateDebut(), criteria.dateFin(),
                criteria.zone(), criteria.prestataire(), criteria.urgent(), criteria.page(), criteria.size(), criteria.canal());
        return cashDemandRepository.search(effectifs.enMasquantLesBrouillons()).map(this::enrichir);
    }

  { code: TOUS,           libelle: 'Tous les types' },

  { code: 'GAB',          libelle: 'Alimentation GAB' },

  { code: TYPE_MONETIQUE, libelle: 'GAB hors site' }
];

/** Options visibles pour l'utilisateur : « GAB hors site » seulement s'il peut consulter le Monétique (CC, Support). */
export function typesDemandePour(habilitations: HabilitationsGdf): readonly OptionFiltre[] {
  return habilitations.consulterMonetique ? TYPES_DEMANDE : TYPES_DEMANDE.filter(t => t.code !== TYPE_MONETIQUE);
}
