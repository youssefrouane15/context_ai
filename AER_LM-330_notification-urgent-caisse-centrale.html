0. Analyse

Règle : à chaque SOUMISSION et MISE_A_JOUR (modification confirmée) d'une demande agence dont l'état après l'action est urgent, un email part vers l'adresse générique de la Caisse Centrale, en plus de l'email agence existant. Couvre les 2 CA : date d'effet lendemain (on ne regarde pas la date), et « passe en urgente à la mise à jour » (on lit urgent après mise à jour). Exclus : annulation (Jira), déclassement (la CC en est l'auteur), canal MONETIQUE (pas d'urgence).
  • Aucun nouveau point d'appel : les use cases appellent déjà notificationDemandeService.notifier(resultat, SOUMISSION | MISE_A_JOUR) avec le DTO enrichi (urgent dérivé des opérations par CashDemandRepositoryImpl.update). Tout se passe dans NotificationDemandeService.
  • Destinataire = configuration gdf.notification.caisse-centrale.destinataires (liste) : devs/Yassine/Omar/Hicham en local, boîte générique en prod via QF_NOTIF_CAISSE_CENTRALE → « modification rapide » sans redéploiement.
  • Même gabarit : nouvel EvenementDemande.URGENCE_CAISSE_CENTRALE (bandeau rouge, « Bonjour Caisse Centrale »), les 4 infos Jira sont déjà dans le template (référence, agence, initiateur) + ligne « Date d'effet » ajoutée (dateEffet du DTO). Maquette PO « en cours » : quand elle arrivera, seul le HTML bougera.
  • Même canal mock / SMTP, même best-effort (jamais d'exception vers le use case). Un échec de l'email agence n'empêche pas l'email CC et inversement.

package com.bmci.q360.domain.retail.enums;

/**
 * AER_LM-277 — évènements qui déclenchent une notification email au Directeur d'agence.
 * AER_LM-333 — ajout du déclassement d'urgence (action Caisse Centrale, l'agence est informée).
 * AER_LM-330 — URGENCE_CAISSE_CENTRALE : demande agence urgente soumise ou mise à jour → adresse générique de la Caisse Centrale.
 * Le verbe forme la phrase « La demande REF {verbe}. » du gabarit.
 */
public enum EvenementDemande {
    SOUMISSION("Création de demande", "a été soumise par l'agence"),
    MISE_A_JOUR("Mise à jour de demande", "a été mise à jour par l'agence"),
    ANNULATION("Annulation de demande", "a été annulée par l'agence"),
    DECLASSEMENT_URGENCE("Déclassement d'urgence", "a vu son urgence déclassée par la Caisse Centrale : elle sera traitée comme une demande non urgente"),
    URGENCE_CAISSE_CENTRALE("Demande URGENTE", "est en attente de traitement et a été marquée URGENTE par l'agence");

    private final String libelle;
    private final String verbe;

    EvenementDemande(String libelle, String verbe) {
        this.libelle = libelle;
        this.verbe = verbe;
    }

    public String getLibelle() { return libelle; }
    public String getVerbe() { return verbe; }
}

/**
 * Notification email d'une demande agence.
 * AER_LM-277 — soumission, mise à jour, annulation par l'agence : le Directeur d'agence (déduit : uid de profil DA rattaché à l'agence).
 * AER_LM-333 — déclassement d'urgence par la Caisse Centrale : tous les utilisateurs « gestion demandes » de l'agence
 *              (rôle GDF Agence : DA et Chef de caisse), un email par destinataire ; repli sur le DA si la liste est vide.
 * AER_LM-330 — demande agence URGENTE soumise ou mise à jour (y compris passée en urgente à la mise à jour) : un email
 *              supplémentaire vers l'adresse générique de la Caisse Centrale (gdf.notification.caisse-centrale.destinataires).
 *              Jamais sur annulation ni sur déclassement (Jira).
 * Best effort : aucune exception ne remonte au use case appelant — la demande est déjà enregistrée, l'email ne doit jamais la faire échouer.
 */
@Service
@Slf4j
public class NotificationDemandeService {

    static final String PROFIL_DA = "DA";
    static final String NOM_CAISSE_CENTRALE = "Caisse Centrale";

    private final UserProfileRepository userProfileRepository;
    private final DirecteurAgencePort directeurAgencePort;
    private final UtilisateursGestionDemandesPort utilisateursGestionDemandesPort;
    private final NotificationPort notificationPort;
    private final GabaritEmailDemande gabarit;
    /** AER_LM-330 : adresses de la Caisse Centrale (liste, vide = pas d'envoi). Test : devs ; prod : la boîte générique. */
    private final List<String> destinatairesCaisseCentrale;

    public NotificationDemandeService(UserProfileRepository userProfileRepository,
                                      DirecteurAgencePort directeurAgencePort,
                                      UtilisateursGestionDemandesPort utilisateursGestionDemandesPort,
                                      NotificationPort notificationPort,
                                      GabaritEmailDemande gabarit,
                                      @Value("${gdf.notification.caisse-centrale.destinataires:}") List<String> destinatairesCaisseCentrale) {
        this.userProfileRepository = userProfileRepository;
        this.directeurAgencePort = directeurAgencePort;
        this.utilisateursGestionDemandesPort = utilisateursGestionDemandesPort;
        this.notificationPort = notificationPort;
        this.gabarit = gabarit;
        this.destinatairesCaisseCentrale = destinatairesCaisseCentrale == null ? List.of()
                : destinatairesCaisseCentrale.stream().map(String::trim).filter(s -> !s.isEmpty()).toList();
    }

    public void notifier(CashRequestDTO demande, EvenementDemande evenement) {
        if (demande == null) { return; }
        notifierAgence(demande, evenement);
        if (concerneLaCaisseCentrale(demande, evenement)) {
            notifierCaisseCentrale(demande);
        }
    }

    // ------------------------------------------------------------------ Agence (277 / 333)

    private void notifierAgence(CashRequestDTO demande, EvenementDemande evenement) {
        try {
            List<UtilisateurAgence> destinataires = destinatairesDe(demande, evenement);
            if (destinataires.isEmpty()) {
                log.warn("[notification] {} {} : aucun destinataire avec email pour l'agence {} — email non envoyé",
                        evenement, demande.getUniqueRequestRef(), demande.getBranchCode());
                return;
            }
            String sujet = "[QlickFlow] " + evenement.getLibelle() + " " + demande.getUniqueRequestRef()
                    + " — Agence " + demande.getBranchCode();
            for (UtilisateurAgence destinataire : destinataires) {
                String corps = gabarit.construire(demande, evenement, destinataire.nomComplet());
                notificationPort.envoyer(new EmailNotification(destinataire.email(), sujet, corps));
                log.info("[notification] {} {} → {}", evenement, demande.getUniqueRequestRef(), destinataire.email());
            }
        } catch (RuntimeException e) {
            log.error("[notification] {} {} : échec de l'envoi, demande non impactée — {}",
                    evenement, demande.getUniqueRequestRef(), e.getMessage());
        }
    }

    /** Déclassement : les utilisateurs gestion demandes de l'agence (repli DA) ; autres événements : le DA. */
    private List<UtilisateurAgence> destinatairesDe(CashRequestDTO demande, EvenementDemande evenement) {
        if (evenement == EvenementDemande.DECLASSEMENT_URGENCE) {
            List<UtilisateurAgence> gestionnaires =
                    utilisateursGestionDemandesPort.utilisateursGestionDemandes(demande.getUser(), demande.getBranchCode());
            if (!gestionnaires.isEmpty()) { return gestionnaires; }
            log.warn("[notification] {} {} : aucun utilisateur gestion demandes trouvé pour l'agence {}, repli sur le Directeur d'agence",
                    evenement, demande.getUniqueRequestRef(), demande.getBranchCode());
        }
        return directeurDe(demande.getBranchCode())
                .filter(da -> da.email() != null && !da.email().isBlank())
                .map(da -> List.of(new UtilisateurAgence(da.uid(), da.email(), da.nomComplet())))
                .orElse(List.of());
    }

    private Optional<DirecteurAgence> directeurDe(String branchCode) {
        if (branchCode == null || branchCode.isBlank()) { return Optional.empty(); }
        return userProfileRepository.uidsParProfil(PROFIL_DA).stream()
                .map(uid -> directeurAgencePort.siDirecteurDe(uid, branchCode))
                .flatMap(Optional::stream)
                .findFirst();
    }

    // ------------------------------------------------------------------ Caisse Centrale (330)

    /** Soumission ou mise à jour d'une demande agence urgente (état APRÈS l'action : couvre « passe en urgente à la mise à jour »). */
    static boolean concerneLaCaisseCentrale(CashRequestDTO demande, EvenementDemande evenement) {
        boolean evenementEligible = evenement == EvenementDemande.SOUMISSION || evenement == EvenementDemande.MISE_A_JOUR;
        boolean monetique = demande.getCanalDemande() != null && "MONETIQUE".equals(demande.getCanalDemande().name());
        return evenementEligible && !monetique && Boolean.TRUE.equals(demande.getUrgent());
    }

    private void notifierCaisseCentrale(CashRequestDTO demande) {
        if (destinatairesCaisseCentrale.isEmpty()) {
            log.warn("[notification] URGENCE {} : gdf.notification.caisse-centrale.destinataires vide — email Caisse Centrale non envoyé",
                    demande.getUniqueRequestRef());
            return;
        }
        try {
            EvenementDemande evenement = EvenementDemande.URGENCE_CAISSE_CENTRALE;
            String sujet = "[QlickFlow] URGENT — " + evenement.getLibelle() + " " + demande.getUniqueRequestRef()
                    + " — Agence " + demande.getBranchCode();
            String corps = gabarit.construire(demande, evenement, NOM_CAISSE_CENTRALE);
            for (String destinataire : destinatairesCaisseCentrale) {
                notificationPort.envoyer(new EmailNotification(destinataire, sujet, corps));
                log.info("[notification] {} {} → {}", evenement, demande.getUniqueRequestRef(), destinataire);
            }
        } catch (RuntimeException e) {
            log.error("[notification] URGENCE {} : échec de l'envoi Caisse Centrale, demande non impactée — {}",
                    demande.getUniqueRequestRef(), e.getMessage());
        }
    }
}

1. Agence (g10002, 1422) : créer + soumettre une demande URGENTE                 → 2 fichiers : DA de l'agence + chaque adresse caisse-centrale
   (vérifier dans le fichier CC : bandeau rouge « Demande URGENTE – <ref> », Date d'effet, 1422 - <agence>, agent créateur)
2. Même demande, soumise après 16h (date d'effet = lendemain)                   → email CC quand même (CA 1)
3. Demande NON urgente soumise                                                   → 1 fichier (DA seul)
4. Demande non urgente soumise, puis Modifier → cocher urgent → Confirmer        → MISE_A_JOUR : DA + CC (CA 2 « passe en urgente à la mise à jour »)
5. Demande urgente, Modifier sans changer l'urgence → Confirmer                  → DA + CC (CA 2 « mise à jour d'une demande urgente »)
6. Annuler une demande urgente depuis l'agence                                   → 1 fichier (DA seul), aucun email CC (Jira)
7. Caisse Centrale : déclasser l'urgence                                         → emails agence (333) seulement, aucun email CC
8. Demande GAB hors site (monétique) soumise                                     → aucun email CC (canal MONETIQUE exclu)
9. Supprimer la propriété caisse-centrale.destinataires (ou la vider)            → log WARN « destinataires vide », DA seul, pas d'erreur
