0. Conception

Où : IdentiteAppelantResolver appelle déjà GET /internal/users/{uid} à chaque appel authentifié (cache 5 min) — c'est le seul endroit où fund-management « voit » l'utilisateur du référentiel, et il ne le voit que s'il est authentifié par le portail (prérequis de la Jira). On y greffe un upsert de retail.user_profile (insert à la 1ʳᵉ connexion, mise à jour ensuite : un changement de profil dans la console est répercuté). Pas d'endpoint, pas de batch, pas de BPMN.
Hexagonal : VO ProfilUtilisateur (domain-core, valueobjects.utilisateur) → port d'entrée SynchroniserUtilisateurUseCase → port de sortie UserProfileRepository.synchroniser → adapter JPA. Le resolver (couche application) ne parle qu'au port d'entrée.
Données : user_profile(uid, profile_code, profile_label, profile_type). /internal/users/{uid} renvoie profile.code et profile.name, mais pas le type (absent de ProfileDTO côté utilisateurs-ci alors que l'entité le porte) → 2 lignes dans utilisateurs-ci pour l'exposer, et ProfilInterneDTO lit name + profileType. Tant que la MR users n'est pas déployée, profile_type est null (pas d'échec : Jackson ignore l'absence).
Jamais bloquant : échec base → WARN, l'appel métier continue (la photo locale n'autorise rien, c'est le JWT + /internal/users qui autorisent).

package com.bmci.workflow.fund.management.service.domain.retail;

import com.bmci.q360.domain.retail.valueobjects.utilisateur.ProfilUtilisateur;
import com.bmci.workflow.fund.management.service.domain.retail.ports.inputs.service.SynchroniserUtilisateurUseCase;
import com.bmci.workflow.fund.management.service.domain.retail.ports.output.repository.UserProfileRepository;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Service;

@Slf4j
@Service
@RequiredArgsConstructor
public class SynchroniserUtilisateurUseCaseImpl implements SynchroniserUtilisateurUseCase {

    private final UserProfileRepository userProfileRepository;

    @Override
    public void synchroniser(ProfilUtilisateur profil) {
        if (profil == null || profil.uid() == null || profil.uid().isBlank()) {
            return;
        }
        try {
            userProfileRepository.synchroniser(profil);
            log.debug("[user-profile] {} synchronisé ({})", profil.uid(), profil.profileCode());
        } catch (RuntimeException e) {
            // La photo locale n'est pas nécessaire pour autoriser l'appel : on trace, on ne bloque pas.
            log.warn("[user-profile] synchronisation impossible pour {} : {}", profil.uid(), e.getMessage());
        }
    }
}
