Feature « Télécharger une demande » — 100% frontend

fund-management-front · Option A : génération CSV native, zéro backend, zéro dépendance npm

OPTION ASANS DÉPENDANCESANS ENDPOINT API

1Cadrage fonctionnel

Le bouton « Télécharger » de la liste des demandes génère un fichier CSV récapitulatif de la demande, entièrement côté navigateur, à partir des données déjà présentes dans le store (l'objet DemandeFonds chargé par loadDemandes()). Aucun appel réseau, aucun endpoint backend, aucune librairie à installer.

Pourquoi CSV natif et pas PDF

  • Zéro dépendance : un PDF exigerait jsPDF via Artifactory — vu l'historique (timeouts, .npmrc, ECONNRESET), on ne fait pas dépendre la feature d'un npm install incertain.
  • Exploitable : le CSV s'ouvre dans Excel (usage bancaire courant), séparateur ; et BOM UTF-8 pour que les accents et le format français passent proprement.
  • Évolutif : si la maquette exige plus tard un PDF formaté (entête BMCI, édition), ce sera un endpoint backend à cadrer avec Yassin — la chaîne construite ici ne changera pas, seul l'adapter d'export sera remplacé.

Contenu du fichier généré

Un bloc entête (demande) puis une ligne par coupure de chaque opération :

BlocColonnes
Entête demandeRéférence (id) · Agence (branchCode) · Établissement · Statut (libellé FR)
DétailOpération (type) · Sens · Urgent · Statut opération · Devise · Coupure · Quantité · Montant devise

2Architecture — où vit chaque morceau

La génération d'un fichier est une préoccupation technique (comme le HTTP) : elle vit donc dans adapters, pas dans le domaine ni dans le composant. La chaîne respecte le pattern du projet :

composant → façade → actions → adapter d'export (nouveau)
FichierActionRôle
adapters\exportAdapters\demande-export.service.tsCRÉERConstruit le CSV depuis DemandeFonds et déclenche le téléchargement navigateur
adapters\localState\fundMangement.actions.tsMODIFIERNouvelle action telechargerDemande(d) — passthrough vers l'adapter, pas d'écriture store

Ce qui ne bouge pas : le port FundService, l'adapter HTTP et le service métier — l'export ne fait aucun appel réseau, il n'a rien à faire dans le port API.

3L'adapter d'export (nouveau fichier)

src\app\features\fund-management\adapters\exportAdapters\demande-export.service.tsCRÉER
import { Injectable } from '@angular/core';
import { DemandeFonds } from '../../domain/domain-core/entities/operation.model';
// ⚠️ Ajuste le chemin d'import selon l'emplacement réel de DemandeFonds

@Injectable({ providedIn: 'root' })
export class DemandeExportService {

  /** Génère le CSV et déclenche le téléchargement navigateur. */
  telecharger(d: DemandeFonds): void {
    const csv = this.genererCsv(d);

    // BOM UTF-8 : indispensable pour qu'Excel affiche correctement les accents
    const blob = new Blob(['\uFEFF' + csv], { type: 'text/csv;charset=utf-8;' });

    const url = window.URL.createObjectURL(blob);
    const lien = document.createElement('a');
    lien.href = url;
    lien.download = `demande-fonds-${d.id}.csv`;
    lien.click();
    window.URL.revokeObjectURL(url);
  }

  /** Construit le contenu CSV : entête demande + une ligne par coupure. */
  private genererCsv(d: DemandeFonds): string {
    const lignes: string[] = [];

    // ---- Bloc entête demande ----
    lignes.push(['Référence', 'Agence', 'Établissement', 'Statut'].join(';'));
    lignes.push([
      this.champ(d.id),
      this.champ(d.branchCode),
      this.champ(d.establishment),
      this.champ(this.libelleStatut(d.requestStatus))
    ].join(';'));
    lignes.push(''); // ligne vide de séparation

    // ---- Bloc détail des opérations ----
    lignes.push([
      'Opération', 'Sens', 'Urgent', 'Statut opération',
      'Devise', 'Coupure', 'Quantité', 'Montant devise'
    ].join(';'));

    for (const op of d.operations ?? []) {
      const baseOp = [
        this.champ(op.operationType),
        this.champ(op.operationSens),
        this.champ(op.isUrgent),
        this.champ(this.libelleStatut(op.operationStatus))
      ];

      const details = op.currencyDetails ?? [];
      if (details.length === 0) {
        // Opération sans ventilation (ex. ramassage) : une seule ligne
        lignes.push([...baseOp, '', '', '', ''].join(';'));
        continue;
      }

      for (const detail of details) {
        const denoms = detail.operationDenominations ?? [];
        if (denoms.length === 0) {
          lignes.push([
            ...baseOp,
            this.champ(detail.currency?.isoCode),
            '', '',
            this.champ(detail.totalAmountByCurrency)
          ].join(';'));
          continue;
        }

        for (const denom of denoms) {
          lignes.push([
            ...baseOp,
            this.champ(detail.currency?.isoCode),
            this.champ(denom.denomination?.denominationLabel),
            this.champ(denom.quantity),
            this.champ(detail.totalAmountByCurrency)
          ].join(';'));
        }
      }
    }

    return lignes.join('\r\n');
  }

  /** Échappe un champ CSV : null-safe, guillemets doublés, encadré si nécessaire. */
  private champ(valeur: unknown): string {
    if (valeur === null || valeur === undefined) { return ''; }
    const s = String(valeur);
    return /[;"\r\n]/.test(s) ? `"${s.replace(/"/g, '""')}"` : s;
  }

  /** Même mapping que le composant liste — statuts techniques → libellés FR. */
  private libelleStatut(s: string): string {
    const map: Record<string, string> = {
      INITIATED: 'En Attente',
      VALIDATED: 'Validé',
      CREATED: 'Validé',
      CANCELLED: 'Annulée'
    };
    return map[s] ?? s;
  }
}
Adapte deux points à ton code réel : (1) le chemin d'import de DemandeFonds ; (2) les noms exacts des propriétés de tes modèles (currencyDetails, operationDenominations, denominationLabel…) — je les ai alignés sur les DTOs du backend, vérifie qu'ils correspondent à operation.model.ts. Si libelleStatut devient dupliqué entre le composant et cet adapter, extrais-le dans un utilitaire partagé de la feature — à ta convenance.

4Actions — fundMangement.actions.ts

Injecter le nouvel adapter (nouveau champ dans le constructeur, à côté de serviceHttp), puis ajouter l'action. Elle est synchrone — pas d'async, pas d'écriture store (un fichier téléchargé n'est pas de l'état) :

5Façade — fundMangement.facade.ts

adapters\localState\fundMangement.facade.tsMODIFIER
  telechargerDemande(d: DemandeFonds): void {
    this.actions.telechargerDemande(d);
  }

Remarque : la signature prend maintenant l'objet complet DemandeFonds (et plus seulement l'id) — c'est lui qui porte les données à exporter, déjà en mémoire.

6Composant — fund-management-list.component.ts

La méthode se simplifie : plus d'async, plus de Blob, plus de createObjectURL — tout est dans l'adapter :

presenter\pages\fund-management-list\fund-management-list.component.tsMODIFIER
telecharger(d: DemandeFonds): void {
  try {
    this.facade.telechargerDemande(d);
    this.snackBar.open('Demande téléchargée.', 'Fermer', { duration: 3000 });
  } catch (e) {
    this.snackBar.open("Erreur lors du téléchargement de la demande.", 'Fermer', { duration: 4000 });
  }
}

Le template HTML est inchangé : le bouton (click)="telecharger(d)" avec l'icône flèche fonctionne tel quel.

7Rollback de la v3 — à supprimer si déjà appliqué

La v3 construisait la chaîne sur un endpoint API inexistant. Si tu avais commencé à l'appliquer, retire ces morceaux :

  • telechargerDemande(id): Promise<Blob> dans le port FundService — à supprimer.
  • telechargerDemande dans l'adapter HTTP (fundManagement-http.service.ts) avec le firstValueFrom vers /cash/{id}/export — à supprimer.
  • L'éventuel passthrough dans le service métier (fundManagement.service.ts) — à supprimer.
  • L'ancienne action/façade qui passaient un id: string — remplacées par les versions de ce doc (objet DemandeFonds).
  • L'import firstValueFrom dans le composant s'il n'est plus utilisé.
Après nettoyage : aucune trace de /export dans le projet — Ctrl+Shift+F sur « export » pour vérifier.

8Checklist de validation

  • Compilation OK (ng serve --proxy-config proxy.conf.json) — aucun nouvel appel réseau, le proxy n'est même pas sollicité par cette feature.
  • Clic « Télécharger » sur une demande avec opérations ventilées → fichier demande-fonds-{id}.csv téléchargé, lisible dans Excel (accents corrects, colonnes séparées).
  • Clic sur une demande CANCELLED → téléchargement fonctionne aussi (statut « Annulée » dans le fichier).
  • Demande avec opération sans ventilation → une ligne avec colonnes devise/coupure vides, pas d'erreur.
  • Rollback v3 vérifié : plus aucune référence à /export ni au port côté HTTP.
  • À montrer à Yassin : si la maquette attend un PDF formaté plutôt qu'un CSV, la seule pièce à remplacer sera DemandeExportService — le reste de la chaîne est acquis.
