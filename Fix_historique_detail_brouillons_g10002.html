3. Libellé des brouillons

fund-management-list.component.ts — libellé de statut ÉDITION

même fichier (Ctrl+F : INITIATED)

  // Libellés affichés dans la colonne Statut — un seul endroit, même vocabulaire que la consultation et la Caisse Centrale
  private static readonly LIBELLES_STATUT: Record<string, string> = {
    INITIATED:       'Initiée',
    SUBMITTED:       'En attente',
    IN_MODIFICATION: 'En modification',
    VALIDATED:       'Traitée',
    CANCELLED:       'Annulée'
  };

  libelleStatut(statut: string): string {
    return FundManagementListComponent.LIBELLES_STATUT[statut] ?? statut;
  }

Si le mapping existant est un switch ou un objet avec d'autres noms, ne change que la valeur de INITIATED : « Initiée ». Le nom de classe dans LIBELLES_STATUT[...] doit être celui de ton composant.

4. Seed retail : g10002 (Chef de caisse, agence 1422)

retail.user_profile — INSERT idempotent pgAdmin, base fund-management

schéma retail

-- Copie le profil de j08221 (Chef de caisse) pour g10002 ; ne fait rien si la ligne existe déjà
INSERT INTO retail.user_profile (id, uid, profile_code, profile_label, profile_type, creation_date, modification_date)
SELECT gen_random_uuid(), 'g10002', p.profile_code, p.profile_label, p.profile_type, now(), now()
FROM retail.user_profile p
WHERE p.uid = 'j08221'
  AND NOT EXISTS (SELECT 1 FROM retail.user_profile WHERE uid = 'g10002');

-- Contrôle
SELECT uid, profile_code, profile_label, profile_type FROM retail.user_profile WHERE uid IN ('j08221', 'g10002');

Colonnes telles que Hibernate les sélectionne dans tes logs (id, creation_date, modification_date, profile_code, profile_label, profile_type, uid). Si id n'est pas un uuid chez toi, remplace gen_random_uuid() par nextval(...) de la séquence de la table. Même INSERT pour tout autre uid du seed qf_admin que tu veux faire jouer en agence (persona DA de la démo si ce n'est pas j43709).
