0. Démarrage bloqué — checksum Flyway V16

Le log (ligne 8) : FlywayValidateException — Migration checksum mismatch for migration version 16 — Applied to database: 1659421088 — Resolved locally: 988449862. V16 a été appliquée une première fois, puis le fichier a été modifié (commentaires). Flyway compare le fichier à ce qu'il a enregistré, voit une différence, refuse de démarrer. mvn clean install passe parce que les tests ne lancent pas Flyway contre cette base.

Règle pour la suite
Une migration appliquée ne se modifie plus : tout changement de contenu part dans V17__...sql. Si tu retouches encore les commentaires de V16, la même erreur revient avec un nouveau nombre — refaire l'étape 2 avec la nouvelle valeur « Resolved locally ». Ne jamais mettre spring.flyway.validate-on-migrate=false : ça masque exactement ce type de dérive.
