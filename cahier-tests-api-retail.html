La campagne de validation du retail migré, sur le modèle du cahier corpo : chaque cas donne le payload Postman, la réponse HTTP attendue, ce que tu dois voir dans chaque table du schéma retail, et le SQL de vérification. 3Cas nominaux

CN-R-01POST/cash201Approvisionnement caisse MULTI-DEVISES (le cas de référence)

Règle vérifiée : Ventilation sur DEUX devises dans une même opération : montant calculé PAR devise (MAD 200×10 = 2000.00 ; EUR 100×5 = 500.00) puis total global (2500.00). Réf RT- générée, défauts serveur, agence/demandeur résolus (obligatoires).

Payload (Body JSON)
{
  "user": "j43709",
  "establishment": "001",
  "branchCode": "AG-CASA-01",
  "operations": [
    {
      "operationSens": "SUPPLY",
      "operationType": "CASH_DESK",
      "isUrgent": "YES",
      "establishment": "001",
      "currencyDetails": [
        {
          "currency": { "isoCode": "MAD" },
          "operationDenominations": [
            { "denomination": { "denominationCode": "BILLET_200" }, "quantity": 10 }
          ]
        },
        {
          "currency": { "isoCode": "EUR" },
          "operationDenominations": [
            { "denomination": { "denominationCode": "BILLET_EUR_100" }, "quantity": 5 }
          ]
        }
      ]
    }
  ]
}

Réponse attendue

  • Statut 201 ; uniqueRequestRef = RT-2026-000001 ; requestStatus = INITIATED
  • Opération : totalAmount = 2500.00, institutionCode 1, cashDeskNumber 001
  • 2 détails devise : MAD totalAmountByCurrency 2000.00, EUR 500.00 — coupures enrichies (label, faceValue)
  • Noter l'id → utilisé par CN-R-04 à CN-R-08

Attendu en base de données

TableCe que tu dois voir
retail.cash_request1 ligne : unique_request_ref = RT-2026-000001, request_status = INITIATED, user_profile_id et establishment_id REMPLIS (résolus j43709/001)
retail.cash_operation1 ligne : operation_sens = SUPPLY, operation_type = CASH_DESK, is_urgent = YES, total_amount = 2500.00, institution_code = 1, cash_desk_number = 001
retail.operation_currency2 lignes : (MAD, 2000.00) et (EUR, 500.00)
retail.operation_denomination2 lignes : (BILLET_200, 10) et (BILLET_EUR_100, 5)
Vérification SQL (pgAdmin)
SELECT cr.unique_request_ref, cr.request_status,
       op.operation_sens, op.total_amount, op.institution_code,
       c.iso_code, oc.total_amount_by_curerency, d.denomination_code, od.quantity
FROM retail.cash_request cr
JOIN retail.cash_operation op         ON op.cash_request_id = cr.id
JOIN retail.operation_currency oc     ON oc.cash_operation_id = op.id
JOIN retail.currency c                ON c.id = oc.currency_id
JOIN retail.operation_denomination od ON od.operation_currency_detail_id = oc.id
JOIN retail.denomination d            ON d.id = od.denomination_id
ORDER BY c.iso_code;
