Bug QA 05/11 — Guide d'utilisation absent tant qu'on n'est pas passé par Gestion des fonds

portail-ci · side-menu : un guide par module natif (assets du shell), GesFond garde le sien (remote) · 05/11/2026

Causeportail-ciRecette

0. Cause

Les 4 liens « Guide d'utilisation » de side-menu.component.html (lignes 93-124) sont tous conditionnés par aideGesfond. Or aideGesfond n'est alimenté que par menuModule.menu$, et menuModule.charger() n'est appelé qu'à l'entrée dans /portail (if (dansGesfond && !estModuleGesfond)). Tant qu'on n'est pas passé par Gestion des fonds, aideGesfond vaut null → aucun guide, même sur Dérogation. Après un passage par GesFond, les 3 autres modules affichent… le guide GesFond (même objet) — c'est aussi un bug.

Fix : l'aide des modules natifs (Dérogation, Mainlevée, Droit de com) est définie dans le shell (AIDES_MODULES, PDF dans assets/guides/), indépendante du remote ; GesFond garde son guide fourni par le MFE. Un seul ng-template pour les 4 liens.
